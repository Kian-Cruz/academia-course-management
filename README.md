# Academia Course Management System

A web-based course management system built with Next.js, TypeScript, and MySQL.

## Technologies Used

- Next.js
- React
- TypeScript
- MySQL
- Docker
- Docker Compose
- Tailwind CSS

## Features

- View available courses
- Add new courses
- Manage course records
- REST API for course management
- MySQL database integration
- Docker-based application deployment

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Docker Deployment

Build and start the application:

```bash
docker compose up -d --build
```
